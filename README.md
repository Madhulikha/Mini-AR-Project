# Mini WebAR Object Demo

A small marker-based augmented reality prototype built with A-Frame and AR.js.

## Run it

1. Upload `index.html` to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Open the published HTTPS URL on your phone and allow camera access.
5. Show the Hiro marker to the camera. The animated 3D object should appear on it.

You can display the Hiro marker from the AR.js documentation or print a Hiro marker image. Keep the marker flat and well lit.

## Notes

- This is a WebAR learning demo, not an official Snap Spectacles/Snap OS app.
- Camera access generally requires HTTPS (GitHub Pages provides HTTPS).
- It uses external A-Frame and AR.js CDN scripts, so an internet connection is required.
- Test on a modern mobile browser. Browser/device compatibility can vary.
